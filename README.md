# Zeta SavedRoom Log

Zetaの非公開トーク（SavedRoom）を、ブラウザ上で収集してHTML / TXTとして保存するための非公式Bookmarkletです。

公開トークではなく、`/saved-rooms/` 上にある非公開トークのログを手元に残したい場合に使用できます。

## できること

- Zetaの非公開トーク（SavedRoom）のログ収集
- 保存したいトークを自分で選択して収集
- キャラクター側 / ユーザー側 / 地の文を判別
- 話者判定を手動で修正
- キャラクター名・ユーザー名の設定
- HTML形式で保存
- TXT形式でコピー
- Zeta風のダークテーマでHTMLを書き出し
- すでに取得した発言と重なるようにスクロールしながら、長いトークを順番に収集

ログの処理・HTML生成はブラウザ内で行います。

## 注意

このツールはZeta公式のものではありません。

Zeta側のHTML / DOM構造を利用しているため、サイト側のアップデートによって突然動かなくなる場合があります。

また、画面にまだ読み込まれていない過去ログを自動的にすべて取得するツールではありません。
保存したい範囲まで実際にトーク画面をスクロールし、発言を表示させる必要があります。

大切なログは、保存後に内容・順番・話者が正しいか確認してください。

## 使い方

### 1. Bookmarkletを登録する

`zeta-log-v3_4-bookmarklet.txt` を開き、中にある

`javascript:`

から始まるコードをすべてコピーします。

ブラウザで新しいブックマークを作り、URL欄にコピーしたコードを貼り付けます。

ブックマーク名は、

`Zetaログ保存`

など、分かりやすい名前でOKです。

### 2. 保存したいZetaのトークを開く

Zetaのブラウザ版で、保存したい非公開トークを開きます。

保存済みHTMLファイルではなく、実際のZetaのトーク画面上でBookmarkletを実行してください。

### 3. 「対象を選ぶ」を押す

画面右下にログ収集パネルが表示されます。

`対象を選ぶ`

を押したあと、保存したいトーク内にあるキャラクターまたは自分の発言本文をクリックします。

イントロ部分ではなく、その後の通常の返信を選ぶのがおすすめです。

選択後、パネルに表示された内容が保存したいトークのものか確認します。

### 4. 「収集開始」を押す

対象が正しければ、

`収集開始`

を押します。

現在画面に読み込まれている発言が収集されます。

### 5. トークをゆっくりスクロールする

長いトークを保存する場合は、Zetaのトーク画面を少しずつスクロールしてください。

前に取得した発言と、新しく表示した発言が少し重なる状態でスクロールすると、発言順を判定しやすくなります。

一気に大きくスクロールすると、前後関係を確認できず収集が止まる場合があります。

その場合は少し戻り、取得済みの発言と新しい発言が同時に見える位置から再開してください。

## 話者を確認する

収集後は、パネル内の話者情報を確認してください。

ツールは可能な範囲で、

- キャラクター側
- ユーザー側
- 地の文

を自動判定します。

判定が間違っている場合や「話者不明」になった場合は、話者確認・修正機能から手動で変更できます。

手動で設定した内容はHTML出力にも反映されます。

## 名前を設定する

キャラクター名やユーザー名を自動取得できない場合は、パネル内の名前設定から指定できます。

例：

キャラクター名
`Noise`

ユーザー名
`響`

別のキャラクターとのトークでも使用できます。
特定のキャラクター名に固定されたツールではありません。

## 保存する

### HTML保存

`HTML保存`

を押すと、収集したトークをHTMLファイルとして保存します。

保存したHTMLは単体でブラウザから開くことができます。

表示は、

- 地の文：中央
- キャラクター側：左
- ユーザー側：右

になるよう整形されます。

### TXTコピー

`TXTコピー`

を押すと、収集した内容をプレーンテキストとしてクリップボードへコピーします。

文章だけ別の場所へ保存したい場合などに利用できます。

## うまく収集できない場合

まず以下を確認してください。

- Zetaのブラウザ版で実行している
- 保存したHTML上で実行していない
- 保存したいトークを「対象を選ぶ」で指定している
- イントロではなく通常の返信を選択している
- 会話をスクロールして発言を実際に読み込んでいる
- スクロール時に取得済みの発言と新しい発言を少し重ねている

Zeta側の仕様変更によって、これまで動いていた機能が動かなくなることもあります。

## プライバシーについて

このBookmarkletは、Zetaの画面上に表示されているトーク内容をブラウザ内で読み取り、ローカルでHTML / TXTに変換します。

このツール自体から、取得したトーク内容を外部サーバーへ送信する処理は行いません。

ただし、BookmarkletはZetaのページ上でJavaScriptを実行する仕組みです。
使用するコードの内容を確認したうえで利用してください。

## 動作について

ZetaのDOM構造に依存しています。

そのため、Zeta側のアップデートによって以下が発生する可能性があります。

- 発言を取得できない
- 話者を判定できない
- トークの並び順を取得できない
- 対象トークを選択できない

問題が発生した場合は、Zetaの画面構造に合わせた修正が必要になる場合があります。
